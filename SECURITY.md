# Security Policy

This repository contains a documentation specification, examples, and validation tooling. Do not commit credentials, personal data, production URLs with privileged access, or sensitive operational material.

If you identify a security concern in the repository tooling or a documentation pattern that could cause unsafe agent behaviour, report it privately to the maintainer rather than publishing exploit details in an issue.

Until a dedicated reporting channel is established, use the repository owner’s GitHub profile to request a private contact path.
