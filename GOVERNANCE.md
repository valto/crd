# Governance

## Maintainer

The initial maintainer and final decision-maker is **Valto Loikkanen**.

## Decision principles

The project prioritizes:

1. The original Minimum Logical Element criterion: contextual logical meaning before process or implementation detail.
2. A small mandatory semantic core with optional extensions.
3. Clear distinction between reusable definitions and operational realizations.
4. Agent-readable documentation that makes facts, inferences, defaults, and unknowns explicit.

Major changes to the core model, mandatory fields, licensing, or governance should be proposed publicly and reviewed as a coherent milestone.
